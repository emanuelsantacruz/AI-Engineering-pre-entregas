# AI Engineering - Entregas

Repositorio con las entregas prácticas de AI Engineering desarrolladas en Python.

## Estructura del Repositorio

- **[pre-entrega-1/](./pre-entrega-1/)**: Cliente de LLM robusto y asíncrono (OpenAI y Anthropic con streaming y Pydantic).
- **[pre-entrega-2/](./pre-entrega-2/)**: Pipeline de procesamiento validado con LCEL y extracción de entidades estructuradas.
- **[pre-entrega-3/](./pre-entrega-3/)**: Sistema de recuperación semántica local (RAG) con ChromaDB y verificación grounded.
- **[pre-entrega-4/](./pre-entrega-4/)**: Sistema RAG escalable en la nube con Pinecone, recuperador híbrido (BM25) y evaluación con métricas Recall@5 y Precision@5.
- **[pre-entrega-5/](./pre-entrega-5/)**: Agente de razonamiento cíclico con LangGraph, herramientas `@tool`, memoria persistente (`SqliteSaver`) y traza ReAct.

Cada carpeta contiene su propio `README.md` con las instrucciones detalladas de ejecución y dependencias en `requirements.txt`.
